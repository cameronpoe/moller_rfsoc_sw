Converts a signed 24-bit ADC value to a signed 32-bit integer.

Reconstructs the 24-bit two's-complement value from its three bytes and sign-extends it to int32_t.

The byte order is interpreted as:

  • b0: bits 23:16;
  • b1: bits 15:8;
  • b2: bits 7:0.
Parameters
[in]xInput 24-bit ADC value.
Returns
Sign-extended 32-bit representation of the ADC value.

int process_fft_block ( const double complex * sig,
size_t start,
size_t fft_len,
double samp_freq,
double * out )
inlinestatic

Processes one complex signal block and shifts its carrier to DC.

Computes the FFT of the selected signal block, determines the dominant frequency bin, and mixes the signal with the negative of that frequency. The resulting complex signal is then phase-rotated so that its average lies on the real axis.

The real part of the final rotated signal is written to out using the same indices as the original input block.

Parameters
[in]sigComplete input array of complex I/Q samples.
[in]startIndex of the first sample in the block.
[in]fft_lenNumber of samples processed in the block.
[in]samp_freqSampling frequency, in hertz.
[out]outOutput array for the real-valued DC signal.
Precondition
sig must contain at least start + fft_len samples.
out must contain at least start + fft_len elements.
fft_len must be a nonzero power of two.
samp_freq must be greater than zero.
Return values
0Signal block was processed successfully.
-1sig or out is NULL.
-2Memory allocation failed.
-3FFT calculation failed.
-4No valid maximum FFT bin was found.

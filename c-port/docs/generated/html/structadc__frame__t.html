Detailed Description

One frame of the raw data input stream as eight 24-bit ADC values.

One frame contains eight ADC values extracted from the raw input stream. In the current data format, these values correspond to the I and Q components of four ADC channels.

The mapping is:

  • ch0: channel 0, I component;
  • ch1: channel 0, Q component;
  • ch2: channel 1, I component;
  • ch3: channel 1, Q component;
  • ch4: channel 2, I component;
  • ch5: channel 2, Q component;
  • ch6: channel 3, I component;
  • ch7: channel 3, Q component;
